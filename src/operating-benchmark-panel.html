Climb fuel flow uses a shared illustrative 0.50 lb/shaft-hp-hour. The optimized window is the quickest tested schedule under this model, not a reconstruction of a pilot's tactical choices. Acceleration during speed changes and a dynamic thermal model are not included.

Aircraft settings, load assumptions and sources

Normal and Combat use the same service-load reconstruction. No bombs, rockets, external tanks or optional gun pods; removable racks excluded.
