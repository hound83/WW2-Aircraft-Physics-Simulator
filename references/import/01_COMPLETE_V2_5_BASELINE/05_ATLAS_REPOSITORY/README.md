# Existing European Air War Atlas v7.5 research and code

The pre-existing GitHub repository, as last checked during this handover, was at commit **d19a1a0475c3b55001bb4c17204d05c53dcce1f5**.

The linked research documents and aircraft-registry code remain in GitHub. **They are not copied here as offline files**, because this environment does not have direct network access for downloadable files and no substitute content is fabricated. Every item has a pinned, reproducible URL in `github_reference_files.json`.

The **standalone physics prototype v0.7 has not been integrated into the website**. The website opt-in preview and v7.4 default fallback must be preserved. The Atlas registry currently has four reported historical test configurations and research placeholders; their generic physics is intentionally disabled.

Use the exact GitHub commit links, not a mutable `main` URL, when checking source comparisons.
