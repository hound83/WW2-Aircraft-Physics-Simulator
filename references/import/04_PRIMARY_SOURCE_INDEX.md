# Primary sources included vs linked

## In the handover, complete original pages

- `03_PRIMARY_SOURCE_PDF/NACA_ACR_L4L07_Vogeley_1944_P47C_Curtiss714_propeller.pdf`: original December 1944 NACA wartime report, 35 pages. NASA citation `https://ntrs.nasa.gov/citations/19930093302`. Page 14 contains Table I (climb coefficient and efficiency measurements), page 15 Table II (high-speed), figs 4–6 on PDF 19–21, figs 8–10 PDF 26–28. Original scanned figure images are accessible from the PDF; original PDF p.14 verifies 20-1 eta .779.
- User supplied P-51B high-speed airspeed-calibration figure and P-47 manual stall excerpt in `04_ADDITIONAL_USER_SUPPLIED_FIGURES`.

## Historical transcriptions / linked originals (audit applicability)

- P-51B-15 43-24777 Wright Field 1944: `https://www.wwiiaircraftperformance.com/org/p-51/p51b-24777.html` — 86 mph IAS, 9270 lb clean power-off shutters closed, but no matched measured correction at stall.
- P-47D 42-26167 Wright Field: `https://www.wwiiaircraftperformance.com/org/p-47/p47-26167.html` — 116 mph uncorrected IAS, 13230 lb takeoff rather than assured stall weight.
- P-47 B/C/D/G pilot operating instructions AN 01-65BC-1: `https://app.aircorpslibrary.com/document/viewer/pfoip470165bc1` — generic clean IAS 115 mph; no matched stall-test weight in included excerpt.
- Spitfire Mk IX notes: `https://stephentaylorhistorian.com/wp-content/uploads/2020/04/spitfire-ix-xi-xvi.pdf`; BS.543 A&AEE speed/climb `https://www.wwiiaircraftperformance.com/org/spitcom/mk9/spitLF-HF-mkIX.html` — different standardized weights for speed and climb.
- NACA 1942 Spitfire Va stall investigation: `https://ntrs.nasa.gov/citations/19930092581` — calibrated test methodology but **different variant**.
- Bf 109F Luftwaffe manual D.(Luft)T.2109 catalog: `https://www.museumalkmaar40-45.nl/voorschriften-manuals/d-luftt/d-luftt-2109`.
- NACA 1943 measured turning F2A-3: `https://ntrs.nasa.gov/citations/19930092640` — valuable method/holdout but not four-aircraft historical turn observation.
- YP-47M 1946 altitude tunnel propeller: `https://ntrs.nasa.gov/citations/20030065899` — distinct propeller and installation; avoid direct P-47B transfer.

See original v2.5 complete source reference catalog for much longer index. It has extracted text and links; **not every indexed NACA original scan is embedded**.
