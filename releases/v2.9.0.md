# v2.9.0 — robustness of the working model

This increment tests whether v2.8 gains survive changes in power, weight and fit/check assignment. It retains the v2.8 working coefficients because none of eight tested fixed candidates passes every documented cross-condition replacement limit. This is a tested robustness result, not a new numerical performance improvement.

- Three explicit fit/check assignments over already-exposed data; original and own-split check metrics remain separate.
- Original-grid and extended Spitfire effective-e searches; near-optimal parameter families and unclipped/configuration-boundary flags retained.
- 27 paired Mustang power/weight combinations at 2200 ft. P beats legacy C in all 27, but mean climb errors range about 20–293 ft/min rather than a universal 9 ft/min.
- Five exact chart nodes calculated without interpolation. Missing higher-altitude climb observations yield null residuals.
- Six Figure 5 points, each with 27 TAS/BHP/RPM scenarios, retain recorded source RPM. Assumed RPM offsets are not measured uncertainty.
- A short expandable explanation is added to the built application. Working calibration identity remains 2.8.0 while the application is version 2.9.0.

The finer original-split Spitfire fit favors e=0.65; lower values worsen agreement. Alternate splits move it to 0.70. Different fits improve some speed/climb rows while worsening others. No new setting is promoted merely because its training score is better. P47 is compared against both v2.8 and its stronger earlier conditional experiment.

Validation: run npm run diagnose:robustness and npm run check. New tests cover fit/check exclusion, original-objective reproduction, exact source-chart coverage, recorded RPM, missing-observation nulls, replacement rejection and UI disclosure. Frozen import checks and all prior regression tests remain in force. Interactive browser testing is reported separately; this increment does not claim historical accuracy or 5:1 proof.
