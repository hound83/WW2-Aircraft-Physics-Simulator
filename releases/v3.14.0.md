# v3.14.0: extensible research evidence and multi-aircraft stall audit

Research-facing simulator milestone. The original aerodynamic solver and v3.13 acceptance baselines are preserved.

- Imports all 553 previously archived performance rows and **173 additional** stall/minimum-speed rows (115 US, 44 international, six original Corsair handbook and eight original NACA Hurricane II) from 134 named original/report-index sources. Includes source fingerprints, stable row IDs, airframe labels and external source links.
- Adds the live **Historical research evidence** panel, including filtering by aircraft, metric, IAS/CAS status, source and observed altitude/weight/speed ranges, with progressive loading and mobile scrolling.
- Uses original speed-basis provenance. `IAS corrected*` is preferred over raw IAS when instrument correction is documented; `CAS*` is only produced from an **applicable numerical correction** within its published range and configuration. The **Corsair manual 75-kt IAS engine-off full-flap stall** now produces the first source-linked **72.5-kt CAS*** candidate (instrument zero-error assumption recorded), while out-of-range Mustang, Thunderbolt, Spitfire and other cases remain unconverted.
- Adds support for arbitrary numeric research ranges, compact versioned JSON packs, **19 original/report-constructed correction curves** (two NACA graphics indexed but not numerically digitized) and knot-table conversion. **Model-specific physical applicability remains separate**.
- Adds archive integrity, provenance, weight/configuration, huge-range, correction math, extrapolation, and browser-level selection checks.

See [`docs/research/WW2_STALL_EVIDENCE_LAYER_2026-11-10.md`](../docs/research/WW2_STALL_EVIDENCE_LAYER_2026-11-10.md) for detailed data counts, source caveats, schema and follow-up.

**Scope qualification:** 173 newly indexed rows do **not** mean 173 independent experiments or calibrated clean one-g CAS observations. The 1946 manual and 1948 tests can be valid documentation for WWII designs without being wartime flight tests. No blanket performance accuracy claim, no new solver aircraft profile and no unverified CLmax recalibration.
