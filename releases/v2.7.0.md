# v2.7.0: explicit source-chart climb-power mode

Adds the shared sourceChartClimb API and npm run diagnose:source-chart. Inputs require matched identity/configuration/RPM, an exact chart node, an explicit lower/midpoint/upper reading, scenario weight and polar. No interpolation or high-blower extrapolation is introduced.

The mode recomputes propeller efficiency and climb with the existing shared solver. At 8,000 and 12,000 ft it adds conditional calculations where the level-flight/ram proxy has no source-bounded power. At 4,000 ft the lower chart BHP reduces climb. Historical climb airspeed and instantaneous mass remain missing, and chart-assigned BHP is not measured torque.

Defaults, coefficients and numerical aircraft inputs remain unchanged. All prior 3,628 baseline values remain unchanged. This is a diagnostic capability and source-integrity improvement, not demonstrated historical accuracy or a v3.0/5:1 pass.
