# v3.1.0 — condition-aware climb improvement

The source-climb calculation now uses a shared fitted response to recorded manifold-pressure ratio, plus nonnegative aggregate configuration drag fitted on the original training altitudes. Both aircraft use the same power-response exponent (0.75); engine-power-dependent cooling loss was tested but not selected. The application and reusable module evaluate the same fixed report conditions.

| Original reserved error | Previous | v3.1 | Reduction |
|---|---:|---:|---:|
| P47 climb MAE, ft/min | 84.7 | 51.3 | 39.5% |
| Spitfire climb MAE, ft/min | 110.2 | 77.9 | 29.3% |

Clean speed curves, Mustang results, source engine curves, source observations, assumed CLmax and legacy default behavior remain unchanged. The improvement is for explicit source-matched climb inputs; generic exploratory controls retain their previous meaning. The model does not infer unknown boost or configuration states.

Both aircraft improve when old/new model forms are refitted on identical alternate training rows. One alternate comparison against retained P47 coefficients still favors the old fit (45.2 vs 59.2 ft/min). Power/mass stress improves 9/9 P47 and 8/9 Spitfire scenarios; the unfavorable Spitfire scenario remains in the report. The fair-refit comparison design was corrected after the first probe and is disclosed. All observations were already exposed.

Validation: npm run diagnose:conditioned-climb; npm run check; npm run test:browser. New tests check no observed-climb input leakage, split exclusion, power budgets/caps, missing boost, immutable inputs, fixed-polar stress, manifest reproduction and clean/Mustang preservation. The browser smoke verifies all 21 source-climb predictions and the fixed-condition panel separately from the exploratory controls.

This is an engineering approximation, not measured engine thermodynamics, independent historical validation or 5:1 proof.
