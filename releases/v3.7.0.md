# v3.7.0 flight-model baseline and first bounded lift update

- Compare working-profile predictions with 69 benchmark records, including the explicit missing Bf 109 climb record. The [scorecard](../docs/FLIGHT_SCORECARD.md) separates speed anchors, condition mismatches and unscored points. The v3.6 predictions are frozen so future changes can be compared on the same observations.
- The clean one-g stall comparison now uses the NACA TN1044 P-51B lift transfer at supported throttled-engine states. At 9,240 lb and 8,000 ft it moves from 98.5 to 103.4 mph EAS. The derived bracket is 102.3–105.2 mph EAS. The applicability window remains 5,100–9,300 ft and Mach 0.14–0.18. Above or below it the comparison displays a provisional estimate. The correction checker requires the relevant cockpit installation.
- The Mustang agreement is with the evidence used to select lift. The original tests used calibrated probes in gradual turns and pull-ups, throttled engine, propeller in high pitch and a carefully finished airframe. The transfer to a steady one-g calculation for 43-24777 remains conditional. All four exact historical clean stall targets remain unresolved. [Primary report](https://ntrs.nasa.gov/citations/19930084610)
- Historical examples for the working level-speed model include 339.1 versus 336 mph TAS for the Bf 109 F-4 at sea level (secondary source), 411.8 versus 412.0 for the P-47B at 34,000 ft, 418.0 versus 410.0 for the P-51B at 32,000 ft and 387.8 versus 381.0 for the Spitfire LF IX at 34,000 ft. The source and modeled loading/configuration caveats are in the [source ledger](../references/performance-evidence.json).
- The stall lift selection applies to the clean-stall calculation. Existing general climb, speed and turn calculations use their existing lift assumptions. Full Mach and Reynolds dependence needs digitised observations and reserved-point checks.

The Rechlin-attributed secondary F-4 figures of 645 and 670 km/h at 7,000 m are tracked as retrieval leads. That altitude is outside the current engine curves for both ratings. The original test conditions are needed to extend the model. [Secondary source](https://info.eduard.com/en/06-2023-1)

Run `npm run diagnose:flight-scorecard` to regenerate the Markdown and point-by-point JSON. Run `npm run check` and `npm run test:browser` for verification.
