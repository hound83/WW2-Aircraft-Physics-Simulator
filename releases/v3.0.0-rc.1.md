# v3.0.0-rc.1 — supported-envelope release candidate

The application now distinguishes a calculable scenario from historical evidence. The shared solver and v2.8 working coefficients remain unchanged. A live coverage panel follows current controls and shows unavailable power states, evidence role, qualified pairwise excess-power differences and exact Mustang chart-power ranges.

The five source-chart nodes use fixed P calibration and their own assumed masses, rather than silently following the current profile/e/weight controls. No unsupported source interpolation is added. Turn/stall accuracy and historical 5:1 discrimination remain unresolved.

The older A/B/C and C one-point P47 diagnostics are explicitly marked legacy. The named Greg Bf109 polar is honored under P and kept outside historical-style pairwise comparisons. No stable v3.0 tag or accuracy certification is created.

Validation: npm run check, npm run diagnose:coverage and npm run test:browser. The browser record includes actual runtime, application version/hash, controls exercised and errors. The new Node assertions cover input gaps, exact chart nodes, pairwise policy, null unsupported values and UI integration. See docs/CURRENT_VALIDATION.md and validation/current/browser-smoke.json for executed results.
