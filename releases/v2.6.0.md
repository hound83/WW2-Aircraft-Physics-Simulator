# v2.6.0: evidence and propeller-validation research increment

This version combines the four-aircraft evidence review, performance reporting, Mustang chart reconstruction and installed-propeller candidate audit. It is a runnable research version. Historical accuracy and v3.0 acceptance remain unresolved.

## Included

- Stall evidence gates for variant/specimen, configuration, installation, correction convention and source-domain applicability.
- Original P-47B 105 mph IAS provenance, F-4 identity/slat checks and corrected Spitfire wing/loading attribution.
- 69 speed/climb records with diagnostic residuals, fitted/dependent roles and explicit exclusions.
- Climb power/cooling budgets and original Mustang Figure 4, with sparse native-pixel weight/power readings.
- C/D/N/M propeller comparisons coupling the original speed anchor, recorded-RPM Figure 5 checkpoints and reconstructed climb states.
- Research-version label in the runnable HTML and version metadata in its build record.

## Propeller result

The inspected sources do not establish an installed K-6523A-24 efficiency map. At the original speed anchor, D/N/M with the unchanged C polar shift predicted speed upward by roughly 4-6 mph. Reanchoring restores that speed but worsens the sampled climb maxima relative to C. Figure 5 diagnostic mean absolute BHP residual falls from about 64 to 50-54; those already-exposed, unmatched checkpoints do not validate a replacement. N/M climb Cp lies below the inherited chart domain.

No default solver coefficient, numerical aircraft input or frozen baseline is changed. All 3,628 existing baseline numerical values remain unchanged. Source weights remain normalization scenarios rather than matched instantaneous climb weights. The known climb failure is preserved.

## Run and inspect

Requires Node 22 or newer, with no npm dependencies:

```sh
npm run check
```

Open `dist/model.html`. GitHub Actions uploads the HTML, `dist/build.json`, validation records and these notes in its `physics-validation` artifact.

[Current validation](../docs/CURRENT_VALIDATION.md) records the actual test count and numerical comparison. [Propeller report](../docs/P51_PROPELLER_EFFICIENCY_AUDIT.md) contains candidate diagnostics and source limits. Interactive browser tests were not run. Passing checks establish reproducibility and guardrails, not historical 5:1 accuracy.

This is a versioned research increment on the Physics repository. It does not deploy or alter the separate Atlas website.
