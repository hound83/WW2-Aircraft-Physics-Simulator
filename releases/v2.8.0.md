# v2.8.0 — joint working-model calibration

The application now selects P, combining shared momentum/loading propeller efficiency, generic tip-Mach/high-J losses, aircraft-specific effective drag efficiency and a nonnegative aggregate drag increment for explicit open-cooling climb states. Shaft-power curves and historical observations remain unchanged. C remains available as the legacy reference; raw API default remains C.

## Result

Conditional Mustang climb MAE at 2200 ft drops from 410.2 to 9.3 ft/min, with 67-inHg fitted and 75-inHg out of parameter fit. Mustang speed MAE rises 2.5 to 3.7 mph; P47 speed MAE improves 3.6 to 0.8 mph. Spitfire speed improves 5.0 to 4.6 mph while climb stays about 103 ft/min. Bf109 speed changes 3.4 to 3.1 mph; no climb observations are available.

Raw C P47 climb MAE 546.4 to 69.8 is not a wholly new gain: the earlier conditional fit already achieved about 44.8. Its reserved-point error is 70.5 versus 84.7 for P. This tradeoff is retained for the joint speed/climb model. See [full report](../docs/V28_RESULTS.md).

## Acceptance and limits

Mustang climb reduction must exceed 30%. Four-aircraft speed checks may regress by at most max(2 mph, 10%); climb checks by at most 50 ft/min, with P47 using its prior conditional baseline. The bounded search includes a drag-only control and stores its top seven candidates. Test the fixed working fit, loading/RPM responses, configuration handling, immutability and Mustang mass sensitivity.

All records were already exposed; the check split evolved during development. These are engineering checks, not independent validation. Spitfire e=0.60 reaches the search boundary; effective coefficients do not identify unique drag/cooling/exhaust/propeller contributions. No new historical turn/stall accuracy or 5:1 proof is claimed.

Run npm run check and npm run diagnose:joint-calibration. CI publishes the built standalone model and validation records. Interactive browser behavior has not been exercised; inline script syntax and active data/engine embedding are checked. Legacy C retains the frozen 3628-number regression separately from deliberate P changes.
