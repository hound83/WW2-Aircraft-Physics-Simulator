# v3.6.0 clean stall comparison

Open the standalone HTML and choose **Compare clean stall speeds**. Set a shared pressure altitude and loaded weights, then read EAS, CAS and TAS in mph. Reset restores the four benchmark weights and 8,000 ft. The model estimates represent a clean one-g stall under fixed lift assumptions. Enter a historical cockpit reading separately in the correction checker with its applicable installation.

At the default loaded weights, the comparison gives these rounded model estimates.

| Aircraft | Weight (lb) | EAS (mph) | CAS at 8,000 ft (mph) | TAS at 8,000 ft (mph) | TAS at 20,000 ft (mph) |
|---|---:|---:|---:|---:|---:|
| P-51B | 9,240 | 98.5 | 98.5 | 111.1 | 134.9 |
| P-47B | 12,565 | 112.3 | 112.4 | 126.6 | 153.8 |
| Bf 109 F-4 | 6,371 | 98.1 | 98.1 | 110.6 | 134.3 |
| Spitfire LF IX | 7,110 | 84.8 | 84.8 | 95.6 | 116.1 |

The separate P-51B test candidate is 103.4 mph EAS, 103.5 CAS and 116.6 TAS at 9,240 lb and 8,000 ft. The candidate transfer is limited to 5,100–9,300 ft and Mach 0.14–0.18, for the report's gradual, throttled-engine and high-pitch test regime. The graph changes the airspeed scale with altitude while holding each selected coefficient fixed.

## Source decisions

- **P-51B.** NACA TN1044 Figure 6 varies Mach and Reynolds number across several altitudes. Its rounded low-Mach lift bracket supports the existing transfer sensitivity. A higher-altitude fit would need digitised test points and a reserved-point check, plus justification for transfer to a clean one-g stall of the modeled specimen. [NASA report record](https://ntrs.nasa.gov/citations/19930084610) · [UNT archived copy](https://digital.library.unt.edu/ark:/67531/metadc56156/)
- **Spitfire LF IX.** The A&AEE report transcription for BF274 describes a level-flight position-error survey down to 130 mph ASI. The production history records that BS274 was marked BF274, a useful cross-reference for archival retrieval. The measured band leaves the IX near-stall correction unresolved. [Test report transcription](https://wwiiaircraftperformance.com/org/spitcom/mk9/spitFmkIX_BF274.html) · [Production history](https://www.allspitfirepilots.org/aircraft/BS274)
- **P-47B.** The original 41-5902 report gives 105 mph IAS and its calibration starts at 170 mph IAS. A secondary discussion repeats 105 mph with the report gross weight. The time-of-stall mass and applicable low-speed correction are still missing. [Original report](../references/sources/p47b-41-5902-phq-m-19-1417-a.pdf) · [Secondary discussion](https://forum.il2sturmovik.com/topic/74337-p-47-maneuverability-or-lack-thereof/page/2/)
- **Bf 109 F-4.** The F-1/F-2 handbook landing data and simulator-derived F-4 numbers provide different configurations or evidence types. The F-4 clean test and applicable airspeed calibration remain retrieval targets. [F-1/F-2 handbook](https://stephentaylorhistorian.com/wp-content/uploads/2020/04/109_f1f2_kennblatt.pdf) · [F-series archive catalogue](https://luftfahrt-archiv-hafner.de/Flugzeuge/messerschmitt.html)

## Acceptance checks

The numerical suite checks all four fighters at sea level, 8,000, 20,000 and 35,000 ft against the one-g lift equation, CAS round-trips and the working solver where an engine result is available. It checks weight scaling, per-aircraft invalid inputs and the shared altitude bounds. The browser suite exercises the individual controls, reset, mobile layout and unsupported correction cases. Run `npm run check` and `npm run test:browser` for the full record.
