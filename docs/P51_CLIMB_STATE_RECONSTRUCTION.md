# Mustang original climb-power and weight reconstruction

Generated by npm run check. Sparse source-pixel readings and conditional model experiments; no default physics correction.

## Source and reading method

[Eng-47-1749-A](https://www.wwiiaircraftperformance.com/org/p-51/p51b-24777.html), Figures 4, 6 and 7, checked against original pixels. The newly retained [Figure 4 scan](../references/sources/p51b-24777-figure4.jpg) supplies a normal-power weight curve for level-speed corrections. It does not establish the instantaneous weight of the high-power climb observations. Figure 7 BHP is engine-chart assigned, not measured flight torque. Figure 6 supplies rate/configuration context but no climb airspeed.

The [coordinate ledger](../references/p51-climb-state-reconstruction.json) records native dimensions, hashes, page numbers, axes, reading boxes and conventions. Each horizontal box plus a 3-pixel axis allowance maps linearly to a bracket rounded outward to 10 lb/BHP. Broad boxes cover line/scan/altitude selection. This approximate local mapping is not a rectified chart, confidence interval or historical error bound. Ambiguous 61-inHg/high-blower branches and shutter readings remain missing. No interpolation is implied.

The joint grid steps 10 BHP and 5 lb, includes interval endpoints, and optimizes TAS from 100 to 290 mph at 1 mph. It recomputes C propeller efficiency through the shared solver at each power/speed, holding the original speed-anchor polar fixed. It is a finite-grid sensitivity experiment, not a continuous bound or independently matched validation. The weight interval is deliberately used only as a counterfactual.

## Acceptance and remaining evidence

Original scan hashes and pixel-to-value mapping are tested. Default solver, aircraft numerical inputs and frozen evidence are preserved. Source weights cannot pass as matched climb weights; absent coordinates remain null. Run npm run check for regression, frozen-import and baseline-difference results. No interactive browser validation was performed.

At reconstructed chart-reading scenarios the existing C model still misses climb. No demonstrated extra chart shaft power or large normalization weight reduction closes the gap. Actual climb TAS/mass, installed efficiency and net cooling/exhaust effects remain unidentified.

Next single milestone: evaluate a source-backed installed K-6523A-24 propeller efficiency model against the reconstructed low-altitude climb-power states and the existing level-flight anchor/Figure 5 constraints, without fitting the climb deficit away.
