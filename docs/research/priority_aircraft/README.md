# Priority Aircraft Primary + Secondary Data Pack v1

Structured minimum-viable performance tables for the 8 priority aircraft (P-51D, P-47D, Bf 109 G-2, Fw 190 A-8, Fw 190 D-9, Spitfire I, Spitfire V, Bf 109 E).

Sources: Wright Field, NACA, A&AEE/RAE, Focke-Wulf, Rechlin/Messerschmitt, Wikipedia references, IL-2, DCS.

All numbers graded; prop efficiency default 0.80; stall mostly IAS from manuals or secondary.

See `all_8_aircraft_primary_secondary_v1.json` for machine-readable values.
