## Direct efficiency evidence

NACA RM L7D10 Table III adds all **62** low-to-high-speed rows for the P-47D-28's modified **three-blade Curtiss 838-1C2-18**. They span **61.1–84.1%**. Each row retains the source advance ratio, power and thrust coefficients, propeller speed, flight and tip Mach, and density ratio. The calculated value $JC_T/C_P$ agrees with the printed efficiency within 0.3 percentage points for all rows. In run 22-15 the published tip Mach is 1.090 and the rounded columns reconstruct 1.0774. The catalog retains both values and the grouped summary omits that run. [NACA RM L7D10, Table III, printed pp. 14–15](https://ntrs.nasa.gov/api/citations/20050019331/downloads/20050019331.pdf)

| L7D10 Table III, advance ratio ≥1.55 | Points | Observed efficiency | Mean absolute error at 80% |
| --- | ---: | ---: | ---: |
| Tip Mach 0.94–1.02 | 11 | 79.5–84.1% | 2.45 pp |
| Tip Mach above 1.02 and below 1.08 | 16 | 74.8–81.6% | 1.50 pp |
| Tip Mach ≥1.08, power coefficient below 0.20 | 4 | 61.1–66.9% | 16.05 pp |
| Tip Mach ≥1.08, power coefficient ≥0.20 | 11 | 67.2–75.2% | 7.59 pp |

The two preceding NACA campaigns provide a separate reference for the same near-sonic tip-Mach band. Seven P-47C Curtiss 714 and P-47D Hamilton 6507A-2 points with $J=1.55$–2.15 and tip Mach 0.94–1.02 gave 78.6–85.2% and a 1.36-point mean error at 80%. The new data support the simple starting value in its tested region and give measured bounds for one installation at high tip Mach. They also show why the power coefficient matters when transferring a high-speed point. [NACA ACR L4L07, Tables I–II](https://ntrs.nasa.gov/api/citations/19930093302/downloads/19930093302.pdf) · [NACA MR L5G09a / WR L-594, Tables I–II](https://ntrs.nasa.gov/api/citations/19930093653/downloads/19930093653.pdf)

## Further report access

- For German blade data, the RAE catalog indexes comments on **ARC 11066**, **RAE TN AERO 1939 / ARC 11439 / DSIR 23/17276**, and German propeller types under **ARC 9516 / DSIR 23/15353**. **RAE AERO 1849 / ARC 10299 / DSIR 23/16136** covers swept-back German test propellers. The full charts and a drawing match for the simulated installations remain open. The G-2 engine installation manual is indexed as **D.(Luft)T. 2109 G-2 Teil 6**. [DSIR propeller records](https://enginehistory.org/References/UKNA/Prop-DSIR.shtml) · [G-2 handbook index](https://www.museumalkmaar40-45.nl/voorschriften-manuals/d-luftt/d-luftt-2109)
- For BS.543, **RAE TN AERO 1728 / ARC 9378 / DSIR 23/15215** is the catalog lead for the metal Rotol test. The scan and its blade drawing are needed before using its coefficients for RA.10061. [DSIR propeller records](https://enginehistory.org/References/UKNA/Prop-DSIR.shtml)
- **NACA RM E6J31** covers the four-blade Curtiss 836-14C2-18R1 on YP-47M. **NACA RM E6K26** covers three- and four-blade Hamilton 6507A-2 on YP-47M. Use the tunnel series to check high-load trends, with each report's tunnel correction and installation limits. [E6J31](https://ntrs.nasa.gov/citations/20030063262) · [E6K26](https://ntrs.nasa.gov/citations/20030065899)
- **NACA ACR 4K02** gives propeller-removed drag for a separate Mustang. Its drag observations can inform an installation comparison alongside L4L18. [NACA ACR 4K02](https://ntrs.nasa.gov/citations/19930092458)

## Build and handoff

Open the [simulator data handoff](../SIMULATOR_DATA_HANDOFF.md) for the current download and build files. Read `fleet_reference` in `fighter-propeller-efficiency.json` and join its observation and source IDs to `research-catalog.json`. The `id` fields match the 13 research variants and `sim_id` maps the seven current model profiles. The original speed traces and uncertainty metadata for WNr 783 are in `fighter-sim-inputs.json` and render in the standalone evidence explorer.

Run `node validation/diagnostics/fighter_propeller_efficiency.cjs --check` and `node scripts/fighter-sim-inputs.cjs --check` to reproduce the companions. Local validation passed 80 regression scripts and compared 3,628 baseline values with zero changes. These replays evaluate input assumptions against named source states. The P-38G, P-51B and Spitfire checks each use held-out points from the same airframe report or test campaign.
