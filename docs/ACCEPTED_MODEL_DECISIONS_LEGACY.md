# User decisions and development principles — locked for continuation

1. **Objective is comparative accuracy, not a perfect P-51B emulator.** Correct relative differences between aircraft are critical. A common small bias can be tolerable, while differing biases that reverse an aircraft advantage are not.
2. **Do not preselect error tolerances.** First measure achievable accuracy. Prioritize stall and low-speed turn accuracy more strongly than an equivalent mph error at maximum speed. Use actual residual plots, altitude-dependent bias and uncertainty of A−B.
3. **One shared engine and aircraft-specific input records**, initially Bf109 F-4, P-47B and P-51B-15. Do not fabricate 89 placeholder aircraft physics; allow a small set selectable as historical reconstructions only when confidence is sufficient.
4. **Use Greg's method as a useful simple foundation.** Model parasite power ~V³ and induced power ~1/V at fixed altitude/weight/1g; induced drag grows with load-factor². Derive or constrain drag split with span, area, mass, Oswald e and test observations; never impose one Golden Number for all aircraft.
5. **Power bookkeeping:** Report engine shaft horsepower, actual propulsive power and thrust separately, no double multiplication by eta. CAS and EAS are distinct, IAS needs aircraft/configuration-specific corrections; drag uses actual dynamic pressure, power requires TAS.
6. **Assumptions are permitted when data missing but must be bounded, labeled and scientifically tested.** Do not silently promote fitted or guessed coefficients to measured historic facts. Match operating weight, boost, gear, cooling, propeller, aircraft specimen and actual test date.
7. **Gregor high-power P-47D-28 2600 hp worksheet is useful.** Share basic Thunderbolt wing geometry and drag formulation with P-47B while retaining version-specific canopy, prop, rating, cooling and mass; D28 worksheet is a regression/sensitivity case, not verified B-type horsepower.
8. **Captured-aircraft reports need special condition annotations.** Battle damage, age, fuel, boost availability, repaired engine, propeller, surface and incomplete testing may affect performance; don't silently substitute representative production performance.
9. **Compare historical observations vs model predictions; do not average them.** Investigate differences, select one fitting condition, withhold others where possible; report both absolute and comparative errors. Model cannot claim calibrated historical turn behavior from max-speed fit alone.
10. **Keep moving toward useful code.** Make a few meaningful improvements per increment, don't multiply research tasks without model progress.
11. **Version releases:** develop/validate generic model outside site; integrate into Atlas v7.5 only after adequate evidence, preserve v7.4 fallback; longer-term comprehensive variant physics in v7.6; nine homepage photos deferred.
12. **User wants a portable handover.** Include original Greg numerical sources and reference tests and entire model version chain.
